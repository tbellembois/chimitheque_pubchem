# AGENTS.md - Chimithèque PubChem Library Agent Guide

First read and follow the global instructions in the [`AGENTS.md`](../chimitheque/AGENTS.md) file.

This `rust` crate is the PubChem connector of the [`Chimithèque`](https://github.com/chimitheque/gochimitheque) application.\

It queries the PubChem online database to autocomplete product names and to get a product by name. The PubChem JSON is parsed into a `chimitheque_types::Product` type, which hold the parsing and validation.
